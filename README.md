# RoboBuilder project website

**RoboBuilder: A Precision Assembly Benchmark for Robot Foundation Models**

Website: https://vineet2104.github.io/RoboBuilder/

This repository contains only the static project website and demonstration
assets. GitHub Pages serves the root of the `gh-pages` branch; `.nojekyll`
disables Jekyll processing. No build step is needed.

The paper, research code and citation are coming soon. This website repository
does not contain the research codebase or its history.

The “Why precision matters” overview embeds `static/videos/precision-comparison.mp4`
with a WebP poster, native playback controls, and a download link. This is an
illustrative Blender animation; its displayed errors describe the constructed
animation and are not recorded benchmark policy results. The overview and
rollout gallery pause each other when playback starts.

The overview loops through an NVIDIA-green RoboBuilder wordmark that unfolds
into the opening terminal panel. Its final frame matches the opening for
continuous playback.

In the closing sequence, the existing RoboBuilder heading descends into the
credits, showing all 12 authors in the website’s order for a brief 1.5-second
hold. The title and every author row then fold together into the terminal
transition to complete the loop.

The terminal prompt uses the NVIDIA eye symbol. A single left-to-right sheen
passes across the completed prompt immediately before submission.
